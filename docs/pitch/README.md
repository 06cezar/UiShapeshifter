# Pitch

- `one-pager.md`: descrierea de o pagină.
- `deck/`: sursa prezentării (15 slide-uri, cu notițele vorbitorului în `<aside>`). Ordinea e în `deck/deck.json`,
  stilul comun în `deck/deck.css`, câte un fișier pe slide în `deck/slides/`. Prezentarea se deschide și se editează în
  deckul „Pitch UI Shapeshifter” de pe claude.ai; copia de aici e cea de la trimitere.

Slide-urile `ideiDemo` și `intrebari` sunt anexe pentru repetiție, nu se prezintă.
